#### What is device driver 
- intigration of two pieces of code
    1. provides services to user space.
    2. communicates with the HW and performs required operations
- as everything is file in linux , device files are present in /dev directory 
- as this are files all the operations which can be performed on regular file using system calls like open(),read(),... can be performed in device files.
-  there are two catogeries of files
    1. char device
    2. block device 
these are - based on speed ,volume of datatransfer and way of organizing the data to be transfered from the device to the system and vise versa
