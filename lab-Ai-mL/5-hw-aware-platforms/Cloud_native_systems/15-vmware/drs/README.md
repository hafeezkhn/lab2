# VMware DRS

## Overview

Learn Distributed Resource Scheduler concepts including resource management, VM placement and workload balancing.

## Topics

- Concepts
- Architecture
- Practical implementation
- Failure scenarios
- Performance considerations
- Interview questions

## Learning Goals

- Understand the fundamentals of VMware DRS.
- Implement small practical examples.
- Understand how this topic is used in modern infrastructure.
- Connect the concepts with distributed systems, Kubernetes, virtualization and cloud infrastructure.

## Recommended Practice

1. Read the fundamental concepts.
2. Draw the architecture.
3. Implement a small example.
4. Test failure scenarios.
5. Measure or observe the behavior.
6. Document the findings.
